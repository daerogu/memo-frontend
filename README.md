# Memo Frontend

클라우드컴퓨팅실습 개인 과제를 위해 제작한 React 기반 메모 애플리케이션 프론트엔드입니다.

Render에 배포된 FastAPI Backend와 API 통신을 수행합니다.

## 주요 기능

- 메모 목록 조회
- 새로운 메모 추가
- 메모 삭제
- FastAPI Backend API 연동
- 개인 소개 페이지 이동 기능

## 사용 기술

- React
- Vite
- JavaScript

## Backend 연동

FastAPI Backend의 REST API를 호출하여 메모 데이터를 조회, 추가 및 삭제합니다.
